Arithmetic Calculator

This project is a simple command-line based arithmetic calculator built using C#. It supports basic mathematical operations including addition, subtraction, multiplication, division, and modulo. Users can input two numbers and choose an operation to perform. The calculator handles invalid inputs gracefully, providing clear error messages for divide-by-zero and non-numeric entries. It also supports continuous calculations using keyboard shortcuts: [Tab] to continue with the result, [Backspace] to reset, and [Escape] to exit.
Ideal for beginners learning C# fundamentals, console I/O, control flow, and method structuring in a modular design.
